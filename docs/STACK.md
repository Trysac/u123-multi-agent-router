# Stack

## Used

| Tool | Why |
|---|---|
| Python >= 3.10 | Modern typing syntax and stability. |
| uv | High-performance dependency management and build system. |
| hatchling | Minimalist, standard-compliant build backend. |
| ruff | Consolidated linting and formatting. |
| mypy | Strict static analysis for runtime safety. |
| pytest | Reliable testing with extensive coverage support. |

## Discarded

| Tool | Why not |
|---|---|
| Poetry | Slower dependency resolution compared to uv. |
| tox | Replaced by single-script CI gates for simplicity. |
